# Nyumbani Support Solutions — Website

Compassion. Dignity. Support. Home.

Static HTML/CSS/JS website for Nyumbani Support Solutions, an in-home care company serving families across Kenya with elderly care, post-discharge recovery, skilled nursing, dementia support, palliative care, and medical equipment rental.

## Structure
- `index.html` — Homepage
- `pages/` — About, Services, Care Packages, Equipment, Family Resources, Contact, Privacy, Terms, individual service pages
- `assets/` — Logo, favicons, caregiver and equipment photography
- `css/style.css` — Single stylesheet, Uzazi-aligned forest green + warm bronze palette
- `js/app.js` — Theme toggle, scroll reveals, FAQ accordions
